# LLM Prompt Templates

This directory contains prompt templates for LLM-based content generation.

The prompts are currently embedded in `src/utils/llm.py` but can be extracted here for easier modification.

## Prompt Categories

1. **Task Name Generation**: Project-type-specific task naming
2. **Task Description Generation**: Varying detail levels and formats
3. **Comment Generation**: Different comment types (general, question, update, approval)
4. **Project Description Generation**: Project overview text

See `DOCUMENTATION.md` Section B for detailed prompt templates and methodology.
